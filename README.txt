# MultiBloom Website

## Run locally
1. Extract the ZIP file (if you downloaded the ZIP).
2. Open the `MultiBloom-Website` folder in VS Code.
3. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together.
4. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Contact form
The form is front-end only and opens the visitor's email app with a prefilled message to multibloom3@gmail.com. It does not store or submit form data to a server. For a real hosted form, connect a backend or form service.

## Before publishing
- Verify all founder statistics and business claims.
- Confirm pricing, delivery timelines, and support availability.
- The site does not promise guaranteed jobs, grades, or publication acceptance.
- The uploaded logo is stored at `assets/multibloom-logo.png`.
